# 第五轮：独立历史POI UID的实测与新景区

日期：2026-10-07。

## 本轮解决了什么

上一轮的uid反查主要使用已知全景basic.poi_id。本轮从三篇腾讯官方历史专题的“查看地点”链接独立提取29个旧UID，全部用xf?uid=...测试：25个有街景ID，4个空。25个逐个/sv成功，其中15个street、4个park、6个indoor。这个比例只描述预先精选的专题样本，不是任意POI命中率。

沿返回点的region.entrances继续追踪，恢复8个新景区相册中的40个不同ID。40个已逐个/sv确认errno=0、basic.svid与请求一致、scenic_id与相册一致。没有把40条都声称为完整图片已验证或普通空间查询全部漏检。

## 独立来源

- 唐代专题（8个UID）：https://web.archive.org/web/20150219032733id_/http://x.map.qq.com:80/wap/v/share/event/1079a63573634bb5bedf3e0b2b0f83df.html
- 名山专题（10个UID）：https://web.archive.org/web/20150321143456id_/http://x.map.qq.com:80/wap/v/share/5586e96b56224e97a9f389ddcb3bc5a3.html
- 情人节专题（11个UID）：https://web.archive.org/web/20150218221626id_/http://x.map.qq.com:80/wap/v/w/detail/8405487e267144f88edf32d6b5a1627b.html

三篇同时保存pano链接和地点链接。本轮有意以独立的地点链接为起点；不是宣称源页面完全没有pano。情人节页的全景链接放在data-href；普通href为javascript:;。

旧地点链接结构：

```text
http://map.wap.qq.com/x/index.jsp?uid={old_uid}&hideAdvert=hide
```

所有UID保持字符串，避免JavaScript Number丢失超过2^53的整数精度。

## 完整示范2：龙门石窟UID→跨区域入口→内乡县衙

```text
8113149553158757159
→ 230331X2130430110514900（龙门石窟，龙门桥）
→ region.entrances.reid = 231331W01502280SCENE001
→ 内乡县衙博物馆，大门
→ photos?id=2313-3-1W0-150228&output=json
→ SCENE001—014
```

14个全部独立验证；入口图实际读取。此挂接跨区域，不能强制用前四位一致过滤，否则漏掉有效点。关联不代表真实步行连通或地理邻近。

## UID关系不是一一对应

丝绸之路群雕历史UID1293231689847890671可返回101630X9130908143712900；但该场景basic.poi_id=8728045137884554093，用后者反查为空。应保存原始历史UID作为独立边，不以最新poi_id覆盖。

三清山金锁酒店与女神宾馆具有不同scenic_id，却返回相同poi_id=2573988128559166544、同坐标、同quit_svid。该UID反查为空。不能按poi_id或坐标合并两套全景。

## 否定结果与下轮线索

- 29 UID中泰山、五台山、泸沽湖、乌镇4个空。它们不意味着对应全景不存在，历史页面本身仍保留pano。
- 在赛里木湖固定坐标r=50，普通xf、追加target=1/2/3、只追加plane=1全部为空。未发现只切一个参数即可普遍扫出隐藏景区的方法。target=2在旧前端用于夜景，target=1/3属于本轮假设测试。
- 第四篇美食专题另提取8个UID，尚未请求：2601663016905006560（河坊街）、10791384793693225720（城隍庙）、12683828947591175720（簋街）、14128920561257989803（锦里）、17778565185749898712（狮子桥）、744691679275104390（磁器口）、13756807699671146588（户部巷）、8124746567700936037（回民街）。来源：https://web.archive.org/web/20150219032806id_/http://x.map.qq.com:80/wap/v/w/detail/7ed76936f84047a0afbc5b1a0f257096.html
